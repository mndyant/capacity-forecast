## 指摘事項（中〜軽微）

**1. 失敗ケースの folds / selections が残留** — `evaluation/final.py:135-138` の except は `rows` から当該ケースを除去しますが、`final.py:117-118` で先に追加された `selections` と `folds` は除去されません。fold は観測データのみ依存なので採点の汚染はありませんが、「同ケースの途中結果は成功として混ぜない」というコメントの方針と `folds.csv` の内容が不整合になります。

**2. 凍結スナップショットの範囲** — `final.py:26` の `snapshot()` は `forecasting/evaluation/scripts` の `*.py` のみで、`app/` と `tests/` を含みません。UIは採点に影響しないので許容範囲ですが、**監査テスト自体が凍結対象外**である点は限界として明記すべきです。また `glob('*.py')` は非再帰のため、将来サブディレクトリを切ると黙って漏れます。git commit も記録されません。

**3. `verify_freeze` の例外型** — `final.py:49-51` は `current` のキーで走査するため、`frozen.json` からキーが欠落した場合は ValueError ではなく KeyError になります。停止はするので実害なし。

**4. 採点途中失敗で出力先が恒久ロック** — `started.json` 書き込み後にクラッシュすると、そのディレクトリは `frozen.json` もあり再freeze・再実行とも不可（上書き禁止の設計通り）。運用手順として「新ディレクトリで freeze からやり直す」を docs に書くべきです。

**5. 開発foldが少数の帯域** — `backtest.py:origins` で n=90〜149 は開発fold 0個（mean30固定・`fallback` 表示あり、正常）。ただし **n=150〜165前後は開発foldが1〜2個**しかなく小標本選択になるのに、UI の注記（`app.js:58`）は fallback 時のみです。

**6. 例外時の500応答** — `app/__init__.py:91` は ValueError のみ400/JSONで返し、想定外の例外は Flask 既定の HTML 500 になります。フロントは `response.json()` 失敗で汎用メッセージにフォールバックするため動作は壊れませんが、やや不親切。

## 問題なしと確認した点

- **リーク**: app側は `data/demo/truth`・`metadata` に一切アクセスせず（サンプル配信も `observed` のみ・ホワイトリスト検証）、truth を読むのは `final.py:121` の評価器のみで、全モデル呼び出し後。fold境界は `backtest.py:36-37` で実行時にも検証。
- **到達日指標**: カテゴリ分離（both_hit/miss/false_alarm/neither_hit/already_full）は正しく、0日誤差への混入なし。符号規約（正=予測遅れ）もレポート記載と一致。
- **UI/API**: DOM更新は全て `textContent` でXSSなし、2MB制限、二重実行防止、CSV検証は網羅的（重複・欠損日・単位・減少・月次を全部拒否）。

## 残存限界（明記推奨）

- `hit_error_days` と `deadline_error_days` は lead+buffer が定数のため**構造上同値**（`final.py:71`）で、独立した検証ではない。同様に `growth_error` は `endpoint_error` と恒等（`backtest.py:16-20`、同一起点のため）。いずれもレポート/UIに注記済みだが冗長な指標。
- 地平線での打ち切り: 正解が地平線直後（例: 91日目）に到達するケースは false_alarm 扱いになる境界検閲があり、誤警報数は過大評価されうる。
- `rate = max(0, raw_rate)`（`models.py:28`）により減少トレンドは原理的に予測不能。非減少データ専用という入力制約と整合するが、モデル側の制約として文書化が必要。
- 凍結の再現性は**指標値レベル**であり、`fit_ms`/タイムスタンプのため出力ファイルのバイト同一性はない。
- 合成6シナリオ×20seedは120の独立環境ではない（report.md 末尾に記載済み、維持すべき文言）。
