# 2分のデモ台本

**0:00〜0:20** 「日々の使用量から、不足する日だけでなく、調達や承認に必要な期間を差し引いた着手期限を出すアプリです。今回は合成データで、実務精度は未検証です。」

**0:20〜0:45** 安定した増加、上限1200GB、90日、整備30日、安全余裕7日のまま実行。現在使用率→容量不足日→着手期限の順に示す。「期限は観測終了日を基準にしています。今日の日付と混同しません。」

**0:45〜1:05** 容量を1000GBへ変更して再計算。「まだ空きがあっても、整備期間を考慮すると期限を過ぎる場合があります。」容量を9999GBへ変えて期間内未到達も示す。「先々まで安全という意味ではありません。」

**1:05〜1:30** 1200GBへ戻し、グラフと増加ペース別の期限を見る。「増加ペースを変えた条件比較です。確率付きの予測区間ではありません。」

**1:30〜1:50** 「精度を確認」を開く。「単純な30日平均とも同じ条件で比較しています。選択に使う期間と監査を分け、未来の行を渡さないテストをしています。単純な予測を下回る結果も残しています。」必要なら docs/evaluation.md で90日評価の悪化を示す。

**1:50〜2:00** JSONまたはCSVを保存。「ローカル・APIキー不要です。業務データでの検証と、構造変化への対応は今後の課題です。」
